Dadway VPN 8.5.6 для Windows

Программа подключает компьютер к серверам Dadway через Xray Core. Доступны локальный прокси и системный режим TUN.

↓ Скачать установщик для Windows x64

Поддерживаются 64-разрядные Windows 10 и Windows 11. Размер файла — около 107 МБ.

1. Установка

  1. Скачайте файл DadwayVPN-Windows-8.5.6-x64.exe.
  2. Запустите установщик и выберите каталог установки.
  3. Если Windows покажет предупреждение SmartScreen, проверьте имя файла и контрольную сумму, затем выберите «Подробнее» → «Выполнить в любом случае».
  4. Запустите Dadway VPN из меню «Пуск» или с рабочего стола.

Для TUN: нажмите правой кнопкой мыши по ярлыку Dadway VPN и выберите «Запуск от имени администратора». Локальный прокси работает без повышения прав.

2. Выбор режима

Откройте Настройки и выберите «Режим подключения».

Локальный проксиВключает системный HTTP/HTTPS-прокси Windows. Подходит для браузеров и программ, использующих настройки прокси системы.
TUN — весь трафикСоздаёт виртуальный сетевой адаптер и направляет через VPN системный TCP/UDP-трафик. Требует прав администратора.

В обоих режимах локальная сеть и сайты в зонах .ru, .by и .su идут напрямую, в обход VPN.

3. Подписки

  1. Откройте Настройки → Подписки.
  2. Нажмите Добавить.
  3. Вставьте полную ссылку, начинающуюся с https://, и нажмите Добавить.
  4. Переключатель включает или отключает источник. Кнопка × удаляет подписку и её локальный кэш.

Можно добавить несколько подписок. Серверы всех включённых источников объединяются в общем списке. При временной сетевой ошибке программа использует сохранённый список; отключённая или истёкшая подписка из кэша удаляется.

4. Подключение

  1. Нажмите карточку Выбранный сервер.
  2. Выберите доступный сервер. Рядом отображаются источник и задержка.
  3. Нажмите большую круглую кнопку Подключиться.
  4. Дождитесь зелёной надписи «Защита включена».

Для завершения соединения нажмите ту же кнопку ещё раз. В режиме прокси программа восстановит прежние системные параметры Windows.

5. Проверка и статистика

  • Проверить IP показывает внешний IP, задержку и приблизительную скорость.
  • Карточка справа отображает режим либо объём принятого и отправленного трафика.
  • Кнопка Обновить список серверов повторно загружает активные подписки.

6. Если подключение не работает

  1. Обновите список и выберите другой доступный сервер.
  2. Для TUN убедитесь, что программа запущена от имени администратора.
  3. Разрешите Dadway VPN.exe, xray.exe и wintun.dll в антивирусе.
  4. Откройте Логи, сохраните диагностический файл и отправьте его поддержке вместе со временем ошибки.

Журнал скрывает UUID, пароли, ключи REALITY и адреса подписок.
