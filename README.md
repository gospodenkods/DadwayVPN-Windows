# Dadway VPN for Windows

Windows-клиент синхронизирован с функциональностью Dadway VPN для Android 8.5.6: несколько управляемых HTTPS-подписок, раздельный кэш, выбор и проверка серверов, VLESS/VMess/Trojan/Shadowsocks, WS+TLS, XHTTP+REALITY, статистика трафика, проверка IP/скорости и подробный обезличенный журнал.

Интерфейс поддерживает системную, тёмную и светлую темы. На главном экране доступна кнопка поддержки проекта, ведущая на официальную страницу CloudTips.

При первой установке добавлена подписка Dadway `https://devel.dadway.ru/sub/zpp#dadway.ru`; в настройках можно добавлять, отключать и удалять другие подписки. Домены в зонах `.ru`, `.by` и `.su` маршрутизируются напрямую.

В шапке приложения отображаются версия сборки клиента и фактическая версия встроенного Xray Core.

В версии 8.3.8 интерфейс переведён на единую сглаженную систему: круглое обрамление логотипа, обтекаемые карточки, окна, кнопки и мягкие тени в обеих темах. Отключённая или истёкшая подписка удаляет локальный кэш, запрещает новое подключение и завершает активное соединение после серверной проверки.

## Запуск из исходников

```powershell
pnpm install
pnpm start
```

## Сборка установщика

```powershell
pnpm dist
```

Готовые файлы создаются в `release`. Офлайн-сборка включает Xray Core, GeoIP/GeoSite и WinTUN из каталога `runtime`.

## Сетевой режим

В настройках доступны два режима:

- **Локальный прокси** — SOCKS5 `127.0.0.1:10808`, HTTP `127.0.0.1:10809` и системный HTTP/HTTPS-прокси Windows.
- **TUN** — виртуальный сетевой адаптер WinTUN для системного TCP/UDP-трафика. Этот режим требует запуска Dadway VPN от имени администратора.

В обоих режимах локальные адреса и домены `.ru`, `.by`, `.su` направляются напрямую. Перед запуском рабочая конфигурация проверяется встроенным Xray; готовность локального SOCKS ожидается до 10 секунд, а сетевой тест повторяется до трёх раз.

## Проверка

```powershell
pnpm check
```

Команда выполняет синтаксическую проверку, unit-тесты парсинга/маршрутизации и валидацию конфигураций встроенным Xray Core.
