# Dadway VPN for Windows

Windows-клиент Dadway VPN: загрузка общей подписки, выбор и проверка сервера, подключение через Xray Core, отображение IP и экспорт журнала. При отключении или аварийном завершении восстанавливает прежние настройки системного прокси пользователя.

Интерфейс поддерживает тёмную и светлую темы с сохранением выбора. На главном экране доступна кнопка поддержки проекта, ведущая на официальную страницу CloudTips.

Официальная подписка загружается только с итогового генератора `https://devel.dadway.ru/sub/promo#https%3A%2F%2Fdadway.ru`. Прямые upstream-ссылки в клиент не встраиваются. Домены в зонах `.ru`, `.by` и `.su` маршрутизируются напрямую, в обход прокси.

В шапке приложения отображаются версия сборки клиента и фактическая версия встроенного Xray Core.

В версии 8.3.9 источник переведён на итоговую подписку `promo`, запросы запрещают промежуточное кэширование, а устаревший локальный кэш `zpp` удаляется при обновлении. Интерфейс использует единую сглаженную систему: круглое обрамление логотипа, обтекаемые карточки, окна, кнопки и мягкие тени в обеих темах.

## Запуск из исходников

```powershell
pnpm install
pnpm start
```

## Сборка установщика

```powershell
pnpm dist
```

Готовые файлы создаются в `release`. При первом подключении приложение загружает официальный Xray Core. Для полностью офлайн-сборки положите `xray.exe`, `geoip.dat` и `geosite.dat` в `runtime` перед сборкой.

## Сетевой режим

Приложение запускает локальные SOCKS5 (`127.0.0.1:10808`) и HTTP (`127.0.0.1:10809`) входы Xray и включает системный HTTP/HTTPS-прокси Windows. Локальные адреса и домены `.ru`, `.by`, `.su` направляются напрямую, как в исходном приложении.

Чтобы реализовать настоящий TUN для всех приложений и UDP, потребуется поставка и подписание отдельного Windows-драйвера (например, WinTUN). Текущая версия не устанавливает драйвер и не требует прав администратора.
